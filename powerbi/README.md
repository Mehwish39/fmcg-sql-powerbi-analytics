# Power BI Report

The final report is stored as `FMCG ERP Analytics.pbix`.

- Built in Power BI Desktop using Import mode.
- Original source: local SQL Server development instance.
- The PBIX can be opened and reviewed without access to that SQL Server because the imported model is stored inside the file.
- Refreshing requires recreating the SQL Server source from the supplied project data/scripts or updating the data-source connection.

Report pages:
1. Executive Overview
2. Sales & Customers
3. Supply & Service
4. Manufacturing & Suppliers
